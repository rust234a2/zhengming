# 事件推演 PRD（v0.3 · 沙盘推演）

版本 v0.3（沙盘推演） · 2026-09-10 · 隶属「争鸣」参赛作品 · 交互原型见 `prototypes/event-replay-prototype.html` · 上游：`debate-tree-PRD.md` / `debate-room-PRD.md`

---

> 命名变更（2026-09-13）：模块名由「事件**复盘**器」改为「事件**推演**」。旧名的重心落在"回顾"上，而本模块的核心动作是**在岔路口做出选择、看模拟后果**——这是推演，不是复盘；叫"复盘器"还与新用户的心智预期相悖（它暗示你进来就能看到真实走向，而产品的第一条规则恰恰是剧透保护）。「复盘」一词仅保留给终局的对照环节。

## 0. 一句话

把真实事件做成**可重走的沙盘**——在事件的关键岔路口做出你的选择，走出一条属于你的路径，再与真实历史并排对照；**模拟层与事实层永远分离，所有分歧点一键接进辩论树**。

## 1. 背景与问题

「争鸣」前两个模块解决了「观点的沉淀（树）」与「观点的交锋（间）」，但议题始终是**抽象问题**（该不该 X）。而知乎上另一大类高质量内容是**事件**：「如何评价 XX」「XX 事件里谁的责任」——它们天然具备辩论议题没有的东西：

1. **具体性与代入感**。事件有当事人、有时间线、有约束条件，「换你会怎么选」比「该不该」更容易让人认真。
2. **确定的后果**。抽象辩论永远可以嘴硬，事件有真实走向可对照——你的推演 vs 历史事实，是辩论树里不存在的**硬锚点**。
3. **天然的分岔结构**。事件的每个岔路口就是一个现成的选择点，分叉图就是一棵现成的树。

但如果直接做「事件模拟器」，会踩三个坑：模拟与事实混在一起变成历史虚无；用户以上帝视角评判当事人；把他人真实的苦难做成娱乐化重演。

## 2. 目标与非目标

**目标**

- G1 沙盘推演：在改编自真实事件的分岔链上做出选择，看到模拟后果，可随时「回到过去」重推。
- G2 模拟/事实双层隔离：默认只进模拟层；真实历史（含知乎溯源）是需主动展开的独立层，推演结束才做完整对照。
- G3 群像选择：每个选择点显示社区的选择分布——「用脚投票」的立场表达，比评论区吵架更温和。
- G4 分歧点直通辩论树：任何选择点/后果节点可一键建局或进入已有辩论树，沙盘里的分歧不蒸发。

**非目标（本期不做）**

- 预测未来（事件推演面向已发生事件，不做走势预测——那是另一个产品）
- 当事人视角剧情（永远第三人称，避免扮演真实他人）
- 事实核查自动化（历史事实层内容来源人工审核 + 知乎溯源，本期不做 NLP 核查）
- 胜负与对错判定（永不做——三个模块共用同一条产品底线）

## 3. 概念模型

### 3.1 事件链（复用树模型的第四种语义）

```
Event（一个改编自真实事件的沙盘）
 ├─ stages      事件节点序列（叙述 + 时间 + 知乎溯源）
 ├─ choices     选择点（挂在事件节点上，2-3 个选项）
 ├─ outcomes    后果节点（选择 → 模拟后果 → 下一事件节点 / 终局）
 ├─ realPath    真实历史路径（哪些选项是当事人真实走的）
 ├─ realSource  真实层溯源（知乎事件类问题 + 回答摘要）
 └─ forks       分叉记录（用户群像的选择分布）
```

节点类型映射（与树同构，仅语义不同）：

| 树 | 事件推演 | 说明 |
|---|---|---|
| `root` | 事件头节点 | 事件背景陈述，全链唯一 |
| `claim` | 选择 / 后果 | 选择是用户的动作，后果是模拟走向 |
| `question` | Host 推演追问 | 指向具体决策假设的追问，不评判 |
| `settlement` | 终局对照卡 | 你的路径 vs 真实历史 vs 群像分布 |

### 3.2 模拟层 / 事实层双层规则（产品合法性核心）

1. **默认剧透保护**：推演过程中界面绝不显示真实走向；「真实历史中发生了什么」折叠需手动展开（展开时该选择点标记「已对照事实」）。
2. **视觉分离**：模拟层用白底卡片，事实层统一用灰底 + 「真实历史」角标 + 知乎来源链接；两者永不出现在同一张卡里。
3. **改编声明**：事件卡固定显示「改编自真实事件，细节已做模糊化处理，当事人非实名」。
4. **对照只在终局**：完整对照（你的路径 vs 真实路径 vs 群像）只在推演结束的终局对照卡中出现。

### 3.3 事件库准入底线

- 只收录**公共讨论充分**的事件（知乎已有问题/高热度讨论），不收录可识别个人的私事。
- 涉及灾难、伤亡的事件不入库（推演 ≠ 消费苦难）。
- 改编规则：人物化名、机构模糊、时间粒度到月。

## 4. 功能需求

### F1 事件推演（P0）

- 事件以时间线逐段呈现；每个选择点暂停，给出 2-3 个选项卡。
- 选项卡显示：选项文案 + 社区选择占比条（薄条，不引导从众——占比默认置灰，选择后才点亮高亮你的选项）。
- 选择后播放模拟后果卡（动画展开），出现「继续推演」；支持「回到这个岔路口重来」。
- 已走过的路径在左侧时间线上实时点亮（路径可视化）。

### F2 真实历史层（P0）

- 每个选择点附折叠项「真实历史中发生了什么」：展开显示真实选项 + 知乎溯源摘要（事件类回答 ≤200 字）+ 跳转原文。
- 终局对照卡：三列并排——**你的路径 / 真实路径 / 群像最常走的路径**，逐岔路口打勾或标差异。

### F3 群像选择（P1）

- 占比数据聚合全站用户选择；样本 < 50 时显示「样本尚少」不显示数字。
- 推演结束显示「与你同路的人还在哪些岔路口和你分开」——同路者的分叉热力，是社交匹配的原料（甜区公式的第四个信号源）。

### F4 分歧点直通辩论树（P0）

- 任何选择点 / 后果节点：「就这个选择开辩论」→ 以「{事件名}里，{选项文案}是不是更优解？」为 root 建新局，或跳入已有辩论树（显示参与人数与最新追问）。
- 从辩论树反向进入：树的 root 若关联事件，显示「进入沙盘重推」入口。

### F5 Host 推演追问（P0）

- 推演中：在你偏离真实路径的岔路口，Host 给一条**假设澄清式**追问（「你选这条路的隐含假设是孩子能适应新环境——这个假设的依据是什么？」），不评判选择本身。
- 终局：Host 输出 2 条推演追问，指向你的决策模式（「你在两次岔路口都选了风险更低的一边——这是风格还是这次事件的特殊性？」），可一键转成辩论树追问节点。

## 5. 关键流程

### P1 一次完整推演

```
事件库选事件 → 逐段阅读 → 岔路口选择（占比置灰）
  → 模拟后果 → 继续（可回溯重推）
  → （可选）岔路口展开真实历史 / 一键开辩论
  → 终局 → 对照卡（你 / 真实 / 群像）→ Host 推演追问
  → 分歧点沉淀进辩论树 → 同路者分叉热力
```

### P2 三模块闭环

```
图谱（发现议题）→ 辩论间（实时交锋）→ 终局 settlement 上树
                                    ↘ 事件推演（事件类议题的沙盘化）
                                        分歧点 → 辩论树 → 又一轮辩论间
```

## 6. 反模式与边界

| 反模式 | 对策 |
|---|---|
| 模拟被当成事实传播 | 双层视觉强隔离；分享卡片强制带「模拟推演」角标 |
| 上帝视角评判当事人 | Host 文案白名单；真实历史层强调「当事人当时的约束 ≠ 你现在的信息」 |
| 消费苦难 / 私事 | 事件库准入三条底线（3.3），人工审核 |
| 剧透毁掉推演乐趣 | 默认剧透保护；对照只在终局 |
| 占比引导从众 | 占比默认置灰，选择后才点亮 |
| 推演无意义刷分布 | 每事件每用户每日重推计 1 次，重推不重复计入群像 |

## 7. MVP 范围与验收

**本期交付**：F1 + F2 + F4 + F5（P0），F3 做静态占比版（无真实聚合）。

**验收清单**

- [ ] 事件分岔链可完整推演，可回溯重走
- [ ] 模拟层默认无任何真实走向泄露；事实层需手动展开且带知乎溯源
- [ ] 终局出现三列对照卡（你 / 真实 / 群像）
- [ ] 偏离真实路径时 Host 给假设澄清式追问，无评判词
- [ ] 任意选择点可一键跳转辩论树
- [ ] 事件卡带改编声明

## 8. 原型说明

`prototypes/event-replay-prototype.html`：知乎风（蓝白黑），事件素材为「老陈事件」（改编自主线议题对应的真实教师流动讨论，人物机构已模糊化），4 层分岔链 + 3 种结局 + 真实历史层（模拟知乎溯源）。占比为静态演示数据。

## 9. 与底座的关系

- 复用树 schema：事件链 = 语义化树；推演追问 = `question` 节点；对照卡 = `settlement` 变体。
- 至此三模块共享同一数据底座：**图谱是索引，辩论间是生产，辩论树是容器，事件推演是题材扩充器**——一个底座，三种体验。
